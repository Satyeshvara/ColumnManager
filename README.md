## How to setup?
- Download 'ColumnManager.exe'.
- Press 'Win + R'.
- Type 'shell:startup' and press ENTER.
- Drop your app here.
- Restart now or double-click the app to run it.

**Shortcut Key:** `ALT` + `` ` ``
